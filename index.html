MULTIMODAL TRANSFORMERS / JUL–AUG 2025 Multimodal Fish-Freshness Classifier Multimodal fish-freshness classification with visual evidence behind model decisions. View project ↗

VISION + NUMERICAL FUSION

A dedicated multimodal model for fish-freshness classification.

Built the main GEMASTIK XVIII research entry by aligning fish imagery and e-nose gas sensor streams, then fusing both modalities through contrastive learning and bidirectional parallel cross-attention.

FUSION-01

Grad-CAM evidence over vision tokens used to inspect the model’s spatial focus.

Context
The main GEMASTIK XVIII research entry: a fish-freshness classifier built from image and numerical inputs.
My role
Parallel fusion architecture, contrastive-learning pipeline, class-imbalance handling, and attention analysis.
Critical decision
Preserve both modalities through parallel cross-attention instead of flattening image and numerical features into one representation.
Data preparation
Aligned DaFiF images and e-nose gas sensor streams with nearest-neighbor timestamp matching, Z-score anomaly filtering, and edge-detection augmentations.
Model architecture
Combined a ViT with a DINOv2 backbone and an MLP sensor encoder, aligned with CLIP-style contrastive loss before bidirectional parallel cross-attention fusion.
Result
Training with Focal Tversky Loss achieved 85.4% accuracy, 84.3% macro F1, and 92.7% peak F1 for the “Marginal” freshness class.

20-CLASS HANDWRITING RECOGNITION

A separate transformer challenge for handwritten Javanese Aksara.

Built an independent image-classification pipeline during the five-hour GEMASTIK XVIII final challenge. CoaT (Co-Scale Conv-Attentional Transformers) captures multi-scale stroke representations across 20 handwritten Javanese script classes.

COAT-20

Confusion matrix showing predictions across 20 handwritten Javanese script categories.

XAI-02

Interpretation output used to inspect structural feature extraction after preprocessing.

Context
A separate five-hour, closed-sandbox final challenge at the national GEMASTIK XVIII competition.
My role
Image preprocessing, class weighting, transformer evaluation, and model interpretation.
Critical decision
Correct class imbalance and compare CoaT, Swin, and EfficientNet rather than trusting raw accuracy.
Training strategy
Used frozen patch-embedding feature extraction followed by progressive fine-tuning with AdamW and Kornia Focal Loss (γ = 2.0, α = 0.25) to address severe class imbalance.
Explainability
Applied Captum Integrated Gradients to generate pixel-level attribution heatmaps and inspect stroke-level attention for shortcut learning.
Result
96.7% test macro F1-score across 20 handwritten Javanese Aksara classes, evaluated through validation and final competition sets.
